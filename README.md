# ระบบออกใบเสร็จรับเงิน มหาวิทยาลัยเทคโนโลยีราชมงคลสุวรรณภูมิ
**Rajamangala University of Technology Suvarnabhumi (RMUTSB) Official Receipt Management Web Application**

เว็บแอปพลิเคชันสำหรับออกใบเสร็จรับเงินในราชการมหาวิทยาลัยเทคโนโลยีราชมงคลสุวรรณภูมิ รองรับการตั้งค่าและแก้ไขข้อมูลผู้ดูแลระบบ (Admin) การเพิ่ม/แก้ไขผู้เข้าใช้งานและรหัสผ่าน รวมถึงข้อมูลตั้งต้นทั้งหมดได้โดยตรงจากหน้าระบบ โดยไม่ต้องแก้ไขโค้ดเมื่อนำขึ้น **GitHub Pages**

---

## ข้อมูลการเข้าสู่ระบบเริ่มต้น (Default Credentials)

### 1. ผู้ดูแลระบบ (Admin)
- **User Admin**: `Admin`
- **Password Admin**: `admin1234`
*(สามารถเปลี่ยนชื่อผู้ใช้งาน รหัสผ่าน และข้อมูลผู้ดูแลระบบได้เองในหน้าระบบที่เมนู **"2. ผู้ใช้งาน"** โดยไม่ต้องแก้ไขโค้ด)*

### 2. เจ้าหน้าที่ (User)
- **เจ้าหน้าที่ออกใบเสร็จ (`issuer`)**: ชื่อผู้ใช้ `staff01` / รหัสผ่าน `123456`
- **เจ้าหน้าที่ตรวจสอบ/เรียกดูอย่างเดียว (`viewer`)**: ชื่อผู้ใช้ `viewer01` / รหัสผ่าน `123456`
*(ผู้ดูแลระบบสามารถกดปุ่ม **"+ เพิ่มผู้เข้าใช้งานใหม่"** หรือกด **"แก้ไขข้อมูล/รหัสผ่าน"** ในตารางผู้ใช้งานได้เองตลอดเวลาจากหน้าระบบ)*

## จุดเด่นที่ปรับปรุงใหม่ (จัดการผ่านหน้าเว็บ 100% ไม่ต้องแก้โค้ดตอนขึ้น GitHub)
1. **เปลี่ยนรหัสและข้อมูล Admin ได้เองในหน้าเว็บ**: ค่าเริ่มต้นคือ `Admin` / `admin1234` และมีกล่อง **ตั้งค่าบัญชีผู้ดูแลระบบหลัก** ในเมนู `2. ผู้ใช้งาน` ให้แก้ไขและบันทึกได้ทันที
2. **เพิ่มผู้เข้าใช้งานและแก้ไขข้อมูลผู้ใช้งานได้เองจากหน้าระบบ**: กำหนดทั้ง `Username`, `Password`, `ชื่อ-นามสกุลที่แสดง`, `รหัสเจ้าหน้าที่`, `ตำแหน่ง`, `บทบาท (admin/user)`, `สิทธิ์การใช้งาน (ออกใบเสร็จ/ดูอย่างเดียว/เต็มสิทธิ์)` และ `สถานะเปิด/ปิด` ได้โดยตรง ไม่ต้องคัดลอก UUID หรือรัน SQL เอง
3. **แก้ไขข้อมูลทุกส่วนได้ในหน้าระบบ**:
   - แก้ไขข้อความหัวเอกสารใบเสร็จ สถานที่ทำการ ชื่อผู้รับเงิน ตำแหน่ง และอัปโหลดเปลี่ยนรูปลายเซ็นผู้รับเงินได้จากหน้าเว็บ
   - เพิ่ม/แก้ไข/ลบ คำนำหน้าชื่อ รายการชำระเงิน ชื่อโครงการ ธนาคารผู้ชำระ และบัญชีธนาคารมหาวิทยาลัยด้วยหน้าต่าง Modal ในหน้าเว็บ
   - แก้ไขข้อมูลเล่มใบเสร็จ และแก้ไขข้อมูลใบเสร็จที่ออกไปแล้วได้โดยตรงในหน้า Admin
   - สำรองข้อมูลและนำเข้าข้อมูลระบบทั้งหมดเป็นไฟล์ `.json` (Export / Import Backup) หรือเชื่อมต่อฐานข้อมูลกลาง Supabase ผ่านปุ่มตั้งค่าบนหน้าเว็บได้ทันที

4. **รูปแบบใบเสร็จรับเงินมาตรฐานราชการ (A5 2 หน้า)**:
   - หน้า 1 แสดงหัวกระดาษ **ต้นฉบับ (Original)** และหน้า 2 แสดง **สำเนา (Copy)**
   - แถวสรุปท้ายตารางเรียงลำดับช่อง **รวมเงิน** (ซ้าย) -> **จำนวนเงินตัวอักษรภาษาไทย** (กลาง พื้นสีฟ้าอ่อน) -> **ตัวเลขจำนวนเงินรวม** (ขวา) โดยคงสัดส่วนความกว้างเดิม
   - ข้อความรับรองท้ายตารางแสดงคำว่า **ได้รับเงินไว้เป็นการถูกต้องแล้ว**
