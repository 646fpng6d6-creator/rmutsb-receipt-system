ระบบออกใบเสร็จรับเงิน

มหาวิทยาลัยเทคโนโลยีราชมงคลสุวรรณภูมิ — ระบบบริหารจัดการและออกใบเสร็จรับเงินผ่านฐานข้อมูลกลางออนไลน์ รองรับการใช้งานหลายเครื่องพร้อมกัน

ระบบจัดการผู้ใช้งานและตั้งค่าผ่านหน้าเว็บ (ไม่ต้องแก้ไขโค้ดเมื่อนำขึ้น GitHub):
• ผู้ดูแลระบบ (Admin) ค่าเริ่มต้น: ชื่อผู้ใช้ Admin / รหัสผ่าน admin1234 (แก้ไขชื่อผู้ใช้และรหัสผ่านได้เองในหน้าระบบ)
• เจ้าหน้าที่ (User) ค่าเริ่มต้น: ชื่อผู้ใช้ staff01 (ออกใบเสร็จ) หรือ viewer01 (ดู/พิมพ์อย่างเดียว) / รหัสผ่าน 123456 (Admin เพิ่ม/แก้ไขผู้ใช้งานและรหัสผ่านได้เองในเมนู "2. ผู้ใช้งาน")

กรุณาเลือกบทบาทผู้ใช้งานเพื่อเข้าสู่ระบบ

เข้าสู่ระบบด้วยชื่อผู้ใช้งาน (Username) รหัสเจ้าหน้าที่ หรืออีเมล และรหัสผ่านที่ผู้ดูแลระบบกำหนดไว้ในหน้าระบบ

เข้าสู่ระบบผู้ดูแลระบบ (Admin Login)

ตั้งค่าการเชื่อมต่อฐานข้อมูลกลาง Supabase

ระบุค่า Project URL และ anon public key / publishable key จากโปรเจกต์ Supabase ของคุณ (ระบบกำหนดค่าเริ่มต้นจากหน้าต่างหลักให้เรียบร้อยแล้ว ทุกเครื่องจะใช้ฐานข้อมูลเดียวกัน)

คำแนะนำ: หากยังไม่เคยสร้างตารางบน Supabase ต้องรัน SQL เพื่อเปิดให้ทุกเครื่องบันทึกข้อมูลร่วมกัน

คำสั่ง SQL สำหรับตั้งค่าตารางบน Supabase

นำคำสั่ง SQL ด้านล่างนี้ไปรันในเมนู SQL Editor บน Supabase Dashboard ครั้งเดียว เพื่อเปิดให้ทุกเครื่องและทุกคนอ่าน/เขียนข้อมูลชุดเดียวกันได้:

เปิดหน้า Supabase SQL Editor ↗

⚠️ สถานะการเชื่อมต่อ Supabase (โปรเจกต์อาจถูกระงับชั่วคราว - Paused)

สาเหตุที่พบ: ระบบได้รับแจ้งเตือน TypeError: Failed to fetch จากเซิร์ฟเวอร์ Supabase เนื่องจากโปรเจกต์ฟรี (Free Tier) บน Supabase จะเข้าสู่สถานะ Paused (หยุดทำงานชั่วคราว) อัตโนมัติเมื่อไม่มีการส่งคำขอติดต่อกันเกิน 7 วัน

🛠️ วิธีแก้ไขและเปิดใช้งาน (กู้คืนได้ทันทีใน 1-2 นาที):

  1. คลิกปุ่ม "เปิดหน้า Supabase Dashboard" ด้านล่างนี้
  2. บนหน้าเว็บ Supabase จะมีแถบแจ้งเตือนพร้อมปุ่ม "Restore project" ให้คลิก 1 ครั้ง
  3. รอเซิร์ฟเวอร์เริ่มต้นการทำงานใหม่ประมาณ 1-2 นาที
  4. กลับมาที่หน้านี้แล้วกดปุ่ม "☁️ ซิงค์ข้อมูลขึ้น Supabase" อีกครั้ง ทุกเครื่องจะเชื่อมต่อและซิงค์ข้อมูลตรงกันทันที!
💡 ข้อมูลตรงกันทุกเครื่องแล้ว: ขณะนี้ระบบได้ฝังข้อมูลตั้งต้น 3 ใบเสร็จ (10,429.99 ฿) ลงในโค้ดเว็บเรียบร้อยแล้ว ทุกเครื่องและทุกเบราว์เซอร์ที่เปิดใช้งานจะเห็นข้อมูลตรงกันทั้งหมด แม้ยังไม่ได้กู้คืน Supabase!

วิธีติดตั้ง Google Apps Script สำหรับส่งอีเมล (ฟรี 100% ตลอดชีพ)

คุณสามารถใช้บัญชี Gmail ทั่วไป หรือบัญชี Google Workspace ของมหาวิทยาลัย (เช่น @rmutsb.ac.th) ในการส่งอีเมลได้ฟรีวันละ 100 – 1,500 ฉบับ โดยไม่มีค่าใช้จ่ายและไม่ต้องเปิดเซิร์ฟเวอร์

ขั้นตอนการติดตั้ง (ทำเพียง 1 ครั้งใน 1 นาที):
  1. เปิดเว็บไซต์ script.google.com แล้วกดปุ่ม "+ New project" (โครงการใหม่)
  2. ลบโค้ดเดิมในหน้าต่างออกทั้งหมด แล้วกดปุ่ม "คัดลอกโค้ด Google Apps Script" ด้านล่างนี้ไปวาง
  3. กดปุ่มสีน้ำเงิน "Deploy" (ทำให้ใช้งานได้) ที่มุมขวาบน > เลือก "New deployment" (การทำให้ใช้งานได้รายการใหม่)
  4. คลิกรูปเฟืองข้าง Select type > เลือก "Web app" (เว็บแอป)
  5. ตั้งค่า:
    • Execute as: Me (อีเมลของคุณ)
    • Who has access: Anyone (ทุกคน) *(สำคัญมาก)*
  6. กดปุ่ม Deploy > กดยอมรับสิทธิ์ (Authorize access) > คัดลอก Web app URL
  7. นำ URL ที่ได้มาวางในช่อง "Webhook URL สำหรับส่งอีเมล" ในระบบออกใบเสร็จ แล้วกดบันทึก
